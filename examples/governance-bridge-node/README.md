# Governance Bridge example

Generic Node sample for any client integrating `@salanor/aegis`.

```bash
cd examples/governance-bridge-node
cp .env.example .env
# Enable AEGIS_ENABLED=1 and fill credentials from console
pnpm install
pnpm start
```

See `docs/AEGIS_GOVERNANCE_BRIDGE_MVP.md` and `docs/AEGIS_N8N_INTEGRATION.md`.
