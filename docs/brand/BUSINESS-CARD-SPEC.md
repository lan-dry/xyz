## Print: dark background

Chrome hides backgrounds unless **Background graphics** is checked.

Steps:

1. Ctrl+P
2. Paper 85 × 55 mm (or Custom)
3. **✅ Background graphics** (More settings)
4. Save as PDF
5. Open PDF: backgrounds must look dark
6. Give **PDF** to printer, not the HTML file

If the shop prints from PDF and it is still white, ask for **“print background colours / rich black”**.
