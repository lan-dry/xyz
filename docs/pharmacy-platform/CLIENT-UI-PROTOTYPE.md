# Client UI prototype (concept screens)

Interactive **high-fidelity concept** for pharmacy online ordering — not the production app.

## Open locally

Double-click or open in Chrome / Edge:

**[client-ui-prototype.html](./client-ui-prototype.html)**

Screens (left menu): client overview, OTP login, catalog, product detail, branch picker, pickup/delivery, Rx upload, cart/insurance, order tracking, delivery OTP, account; staff Rx review, fulfilment, handover, PMS sync, insurance claims, owner settings.

## Send to the client

| Method | Steps |
|--------|--------|
| **PDF** | Open HTML → **Ctrl+P** → Save as PDF (enable background graphics). |
| **Link** | Host on Vercel/static bucket, or attach the `.html` file (works offline). |
| **Figma** | Import screenshots per screen into Figma, or redraw using these as reference (see below). |

## Figma (full `.fig` file)

Cursor cannot export a native Figma file. To get a real Figma deck:

1. Screenshot each screen from the prototype (or Print to PDF → import pages).
2. In Figma: **File → New** → paste frames at **390×844** (patient) and **1440×900** (staff).
3. Optional: use a free UI kit (e.g. “Health app”, “E-commerce mobile”) and restyle to pharmacy colors from the workshop.

Salanor can quote **visual design + Figma handoff** as a separate line if the client wants editable source files.
